# Multi-Agent Coding Workspace Landscape — June 2026

## Dedicated orchestrator apps (local-first)

**Conductor (Melty Labs, conductor.build)** — macOS-only GUI; raised $22M Series A. Spawns parallel Claude Code, Codex, and Cursor agents, each in an isolated git worktree per "workspace"; workspace forking, multi-repo support, pinning, instant archiving. Review: dedicated Diff Review Panel (Sept 2025), historical diffs, custom review models (Nov 2025), automated spec/plan review for logic errors. Multi-provider: Claude/Codex/Cursor + Bedrock/Vertex/custom providers; agent configs sync across machines (May 2026); Fable 5 support shipped June 9, 2026. Pricing: free, BYO subscription; paid collaboration tier planned. Sources: https://www.conductor.build/changelog, https://docs.conductor.build/, https://rustman.org/wiki/conductor-parallel-agents/

**Crystal → Nimbalyst (Stravu)** — Crystal (open-source Electron, parallel Claude Code/Codex sessions in worktrees, run/test scripts, conversation continuity) was deprecated Feb 2026; successor **Nimbalyst** adds visual planning, kanban session management, file traceability, diff review, and a native iOS app for remote session monitoring (unique in category). Providers: Claude Code, Codex, OpenCode/Copilot (alpha). Free for individuals; Teams pricing TBD. https://github.com/stravu/crystal, https://nimbalyst.com/crystal/, https://nimbalyst.com/blog/best-agent-management-tools-2026/

**Claude Squad (smtg-ai)** — most popular open-source terminal orchestrator (~6.9k stars, AGPL/MIT-listed variously). tmux session per agent + git worktree per branch; TUI to create/pause/resume/delete up to ~10 concurrent instances; diff preview in TUI. Providers: Claude Code, Codex, OpenCode, Amp, Aider, Gemini. Free. https://github.com/smtg-ai/claude-squad

**Sculptor (Imbue)** — container-per-agent (Docker) instead of worktrees: agents execute code safely in parallel without sharing local env. "Pairing Mode" syncs an agent's container work into your local repo/git state one click at a time; plain-English code-quality rules ("never use eval") enforced via automated review of agent output. Anthropic-backed (API key or Pro/Max plan); model-agnostic claim, not a CLI wrapper. Mac (Apple Silicon) + Linux. Free in beta. https://imbue.com/sculptor/, https://github.com/imbue-ai/sculptor

## IDE/editor-native

**Cursor 3.x** — Agents Window (Cursor 3 "Glass") replaced Composer: run many agents locally, in worktrees, in cloud, or over SSH; up to 8 parallel background agents in isolated worktrees; `/multitask` fans out async subagents; `/worktree` moves a chat into an isolated checkout; `/best-of-n` runs one task across multiple models. Pricing: Free/$20 Pro/$60 Pro+/$200 Ultra, but cloud-agent metering is separate — real-world spend $200–$1,800+/mo reported. Cursor also authored **agent-trace**, an open line-level AI-attribution spec (see below). https://cursor.com/docs/configuration/worktrees, https://devtoolpicks.com/blog/cursor-3-agents-window-review-2026, https://aiproductivity.ai/blog/cursor-pricing/

**VS Code / GitHub Copilot** — four agent types (local, background, cloud, sub-agents); Agents window + standalone "Agents companion app" (Insiders preview, April 2026) for agent-native development; May 2026 added multiple simultaneous agent sessions side-by-side. Build 2026: planner-and-specialist multi-agent orchestration (orchestrator decomposes, delegates to subagents). Attribution flashpoint: `git.addAICoAuthor` Copilot `Co-authored-by` trailer was briefly on by default (Apr 16, 2026), backlash forced reversal May 3, 2026. https://code.visualstudio.com/docs/copilot/agents/overview, https://code.visualstudio.com/blogs/2026/02/05/multi-agent-development, https://windowsforum.com/threads/vs-code-copilot-co-author-trailer-backlash-ai-provenance-opt-out-restored.416417/

**Zed 1.0** — Agent Panel with editable diff review, follow mode, background agents; bet on concurrency: multiple agents on isolated worktrees, bounded only by rate limits. Key contribution: **Agent Client Protocol (ACP)** — Claude Code, Codex, Gemini CLI, OpenCode run *inside* Zed as external agents owning their own runtime/auth/models. https://zed.dev/acp, https://zed.dev/docs/ai/external-agents

**Google Antigravity 2.0** — free agent-first IDE (Gemini 3.x + Claude Opus 4.6 built in); Manager View / "Mission Control" dispatches up to 5 parallel agents across workspaces; 76.2% SWE-bench Verified. 2.0 (I/O, May 19, 2026) added desktop app rebuild, Go CLI, SDK, Managed Agents billing tier. Pain point: four undisclosed quota cuts in four months; $20/mo Pro. https://aicoderscope.com/blog/google-antigravity-review-2026/, https://developers.googleblog.com/build-with-google-antigravity-our-new-agentic-development-platform/

## Cloud-agent platforms

**OpenAI Codex** — cloud sandbox per task, parallel tasks, unified state across desktop app/CLI/IDE/web; built-in worktrees; "Automations" do unprompted work (issue triage, CI, alert monitoring); GA subagent model with manager coordinating parallel workers; GitHub/Slack/Linear integration. Pricing reshuffle Apr 9, 2026: Pro 5x $100/mo (direct answer to Claude's $100 tier), old $200 Pro → Pro 20x. https://developers.openai.com/codex/cloud, https://www.eesel.ai/blog/openai-codex-pricing, https://www.developersdigest.tech/blog/claude-code-vs-codex-app-2026

**Devin (Cognition)** — raised at $26B (May 2026). Feb 2026: parallel sessions; main Devin delegates to "managed Devins," each a full Devin in its own VM, with the coordinator scoping, monitoring, conflict-resolving, compiling results. ACU consumption pricing: Core from $20 ($2.25/ACU), Team $500/mo (250 ACUs, unlimited concurrency). Independent testing: 67% PR merge rate on well-defined tasks; ~85% failure on ambiguous ones. https://devin.ai/pricing, https://www.techtimes.com/articles/317354/20260529/ai-coding-agents-cognitions-26b-raise-bets-agent-first-architecture-beats-ide-tools.htm

**Warp** — AI terminal with agent mode (configurable autonomy, live task lists, interruptible/redirectable agents) plus **Oz**, cloud platform running parallel autonomous agents (~$200/mo tier; Enterprise gets Oz access). Pricing ladder: Free 75 credits → Build $20 → Turbo $40–50 → Lightspeed $200; BYO API key supported. https://www.warp.dev/pricing, https://www.implicator.ai/warp-turns-the-terminal-into-an-agent-platform-at-200-a-month/

**Amp (Sourcegraph)** — terminal CLI + VS Code extension; shareable threads, auto-spawned subagents with own context windows, "oracle" advisor tool (GPT-5.5 high reasoning); `/handoff` removed May 2026 (compaction obsoleted it); agentic code review shipped; Sourcegraph code-graph context. Pricing: Amp Free (ad-supported, since Oct 15, 2025) + pay-as-you-go credits with no markup; Cody now enterprise-only at $59/user/mo. https://ampcode.com/manual, https://sourcegraph.com/amp

**Claude Code (Anthropic)** — Agent Teams shipped Feb 2026 (experimental, `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`): a lead session spawns teammates with own context windows, shared task list, peer-to-peer mailbox messaging; each teammate in an independent worktree; ~3–4x token cost of sequential. Subagents remain for isolated report-back work. Official worktree docs for parallel sessions. Pricing: Max $100/5x or $200/20x. https://code.claude.com/docs/en/agent-teams, https://addyosmani.com/blog/claude-code-agent-teams/, https://code.claude.com/docs/en/worktrees

## Attribution/provenance state of the art
- **agent-trace** (Cursor, spec'd ~May 2026): line-level human/ai/mixed/unknown attribution committed as JSONL in-repo; not yet default anywhere; positioned as the EU AI Act (enforcement Aug 2026)/ISO 42001/SOC 2 artifact. https://axiomstudio.ai/blog/cursor-agent-trace-explainer
- **git-ai**: line-level attribution (agent, model, session) in Git Notes; supports Claude Code/Copilot/Cursor/Windsurf; on Thoughtworks Radar. https://github.com/git-ai-project/git-ai
- Copilot co-author trailer default-on backlash shows users want provenance but demand consent/control.
- Research: agents are fingerprintable from commit style (https://arxiv.org/html/2601.17406v1). Notably, **no orchestrator GUI ships deep attribution as a core feature** — Nimbalyst's "file traceability" is the closest.

## (a) Table-stakes checklist
Parallel sessions with per-agent isolation (worktree or container); session dashboard with status-at-a-glance; integrated diff review + merge/PR flow; multi-provider CLI support (Claude Code + Codex minimum, ideally Gemini/OpenCode/Amp); BYO subscription/key (free shell, paid model); run/test scripts inside the workspace; conversation persistence/resume; archiving/cleanup of stale worktrees.

## (b) Emerging differentiators
Container isolation over worktrees (Sculptor); remote/SSH + mobile oversight (Mux, Emdash, Nimbalyst iOS); autonomous task decomposition and conflict resolution (Composio, Codex Automations, Devin managed-Devins, Vibe Kanban MCP planning); best-of-N / cross-model A/B (Cursor, Parallel Code); inter-agent messaging + shared task lists (Claude Code Agent Teams); automated spec/plan review and custom review models (Conductor); plain-English quality rules (Sculptor); line-level provenance (agent-trace/git-ai — spec'd but unshipped in products); ACP-style protocol interop (Zed); issue-tracker integration (Linear/Jira/Slack).

## (c) Taime vs the field
**Strong:** Attribution is a genuine white space — every competitor treats diff review as the provenance story; none ships line/session-level "who wrote this and why" natively, while compliance pressure (EU AI Act Aug 2026, the Copilot co-author backlash) is making provenance a purchasable feature. Adopting/emitting agent-trace or git-ai-compatible records would make Taime first-to-market in GUI form. Local-first + CLI-driving matches the proven Conductor/Claude Squad model, avoids Cursor/Devin's runaway cloud metering, and daemon-owned PTY/process management is harder-won infrastructure than most Electron wrappers have. Safe context switching maps to a real pain (review is the bottleneck, per the whole category). **Weak:** Free is the entrenched price (Conductor, Superset, Antigravity, Amp Free) — monetization must come from teams/compliance, not the shell. Crowded field with funded players (Melty $22M, Cognition $26B valuation) and OS-platform gravity (VS Code Agents app, Zed ACP, Antigravity). Missing-vs-field risks: no container isolation story (Sculptor's safety pitch), no remote/SSH/mobile oversight (Emdash/Mux/Nimbalyst), and multi-provider breadth (22+ agents on Emdash) is becoming expected; worktree-only isolation and macOS/local-only scope are no longer differentiating on their own. The category's stated trajectory — human-conductor → autonomous-orchestrator — suggests Taime's Flows/Routines direction is correctly aimed, but attribution + review UX is where it can win now.
